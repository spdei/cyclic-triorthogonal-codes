# Cyclic triorthogonal codes in prime dimension

Code and data for the paper *Cyclic triorthogonal codes in prime dimension* by Shiroman Prakash.

The code enumerates cyclic triorthogonal codes for p = 2, 3, 5, 7 using sumset conditions on
spectral supports. It certifies their distances, and computes their distillation performance.

## Requirements

- Python 3.8 or later, with numpy (`pip install -r requirements.txt`).
- A C compiler (`gcc`). The two C tools in `csrc/` are compiled automatically on first use.
- GAP, PARI/GP and Magma are needed only to regenerate the coset data or to rerun the
  cross-checks. The outputs of those programs are included.

## Contents

```
triortho/   Python package: linear algebra over F_p, cyclotomic cosets, cyclic codes, the
            support search, triorthogonality and transversal-gate checks, certified distances
csrc/       meet-in-the-middle distance search with verified witnesses
            (dwit.c for odd p, bdist.c for p = 2)
data/       cyclotomic cosets and minimal polynomials, generated by the scripts in datagen/
results/    every maximal support, with its dimension and certified distance
            (binary_results.json: p = 2, odd n <= 763; qudit_results.jsonl: p = 3, 5, 7)
scripts/    search_binary.py, search_odd.py   the searches
            make_tables.py                    Appendix B (LaTeX), from results/
            paper_tables.py                   Tables 1 and 2, and other numbers quoted in the text
            threshold.py                      exact distillation performance (MacWilliams identity)
            compare_magma.py, compare_magma_qudits.py   cross-checks against magma/
magma/      independent Magma searches and their output, and resolve-distances.m, which computes
            exact distances for codes left as lower bounds by the Python search
tests/      self-checks
```

## Reproducing the paper

```
python scripts/search_odd.py 3 121      # likewise 5 96 and 7 96
python scripts/search_binary.py 3 763   # several hours
python scripts/make_tables.py           # Appendix B; --out FILE writes it to a file
python scripts/paper_tables.py          # Tables 1 and 2 (a few seconds)
python scripts/compare_magma.py         # binary cross-check: prints ALL AGREE
python scripts/compare_magma_qudits.py  # qudit cross-check: prints ALL AGREE
```

The files in `results/` are the outputs used in the paper. The searches write to
`results_p*.jsonl` in the current directory (`--out` changes this), so they never overwrite
`results/`. Note that `search_binary.py` appends to its output file.

## What the distances mean

Every reported distance is certified.

- **Exact:** an explicit minimum-weight witness was found and re-verified independently, and an
  exhaustive search shows that no smaller weight exists. Some exact distances were instead
  computed with the Brouwer-Zimmermann algorithm in Magma (`magma/resolved_distances.csv`).
- **Lower bound:** the exhaustive search was run up to a weight cap and found nothing, so the
  distance is at least that value.

In Appendix B an entry is exact only if the distance of every maximal support at that length is
exact. Otherwise it is printed as a lower bound, or as a range a-b when every support has a
finite upper bound. Lower bounds also use the concatenation result (Proposition 18): a support
that contains the concatenation of two construction-A supports, of distances d1 and d2, has
distance at least d1*d2, with equality when it equals that support.

## Self-checks

`python run_checks.py` takes about a minute. Each component is compared with an independent
method:

- linear algebra and minimal polynomials, against direct computation and the GAP/PARI data;
- the spectral lemma and the sumset criteria of both constructions, against direct trilinear
  checks, and the search against brute force over all coset unions;
- both C tools and the distance formulas, against brute force;
- the transversal gate on the codes given in the paper, with exact mod-9 phases for p = 3;
- the record codes and the two MDS families, end to end;
- the rules used in Appendix B.
